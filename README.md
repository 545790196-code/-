# 户用分布式光伏容量查询数据库

公开开放容量查询相关资料库。

## 目录结构

```
├── README.md              # 本说明
├── data/
│   ├── cases.json         # 真实户用光伏安装案例（来自公开渠道）
│   ├── specs.json         # 各地户用光伏建设管理规范（倾角/限高/排布）
│   └── components.json     # 主流组件参数（650W等）
└── scripts/               # 计算与出图脚本
```

## 核心结论（基于规范与案例）

- **650W 组件**：2382×1134×30mm，单块面积约 2.70㎡，功率 0.65kW
- **平屋面倾角**：户用项目受限高约束，常见 5°–19°，最高处距屋面 ≤1.5–2.3m
- **坡屋面**：顺坡安装，组件与屋面垂直高度 ≤0.3m，不超出屋面外沿
- **可用面积系数**：屋面投影面积 × 80% 为可铺组件面积
- **前后排间距**：保证冬至日 9:00–15:00 不遮挡

## 数据来源

- 各地政府公开发布的户用光伏建设管理通知
- 国家能源局四川监管办《户用光伏建设运行百问百答》
- 北京《建筑光伏系统设计指导性图集》
- GB 50797-2012《光伏发电站设计标准》
- 公开项目方案（和县功桥、泰州高港、靖江别墅等）
